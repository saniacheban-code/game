# Учебная арена — общая основа

Полная сборка: **18 предметов, 16 игр, 30 сочетаний игры и режима**. Добавлены шесть [предметов начальной школы](docs/primary-school.md): познание мира, букварь и обучение грамоте, литературное чтение, музыка, изобразительное искусство, трудовое обучение. В них 80 тематических блоков по четвертям и разделы повторения, 440 авторских карточек и вычисляемые варианты.

Новая игра — [«Хранители маяка»](docs/lighthouse.md): ответы дают энергию, повороты модулей собирают световую цепь, завершённый маршрут зажигает маяк. Соло на три острова или одновременная дуэль. Нарисованы новый фон, маяки, хранители и лодка; анимации встроены. Прежние банки и игры сохранены.

Ниже — описание общей основы и предыдущих дополнений. Запуск всей сборки: `index.html`.

Новая игра: [правила и устройство «Штурма мастерских»](docs/siege.md). У каждого по 8 заводных сов; верные ответы запускают их в укрепление соперника, ошибки расходуют запас. Побеждает большее разрушение.

Новое: [«Лови ошибку: строительство небоскрёба»](docs/builder.md) — сборка формул и фраз перетаскиванием, 150 секунд, ровные и перекошенные этажи, обрушение после шести ошибок. Все десять карточек игр получили новые иллюстрации.

Обновлено оформление [самолётов и леса](docs/visual-refresh.md): новые самолёты, препятствия, фоны и персонажи; полная ширина лётного поля; ответы закреплены на лесных табличках. Эти изменения проверены в настольном браузере. Ниже сохранены описания и результаты проверок предыдущих этапов.

Исправлены [пропорции небоскрёбов и фонов](docs/proportions-fix.md): равномерное масштабирование, нормальная высота этажей и персонажей. Проверено в настольном браузере.

Новая игра: [«Экспедиция» / «Картограф»](docs/expedition.md) — исследование острова 7 × 7, туман неизвестности, реки, горы, сокровища и хранители. Соло с помощником или поочерёдная дуэль на одинаковой карте. Нарисованы фон, объекты и два исследователя.

Новое: [«Неон-паркур»](docs/parkour.md) — одновременный забег на двоих или одиночное испытание, три воротца ответов, буст и суперпрыжок. Нарисован фон обсерватории, спрайты героев переиспользованы из сборника с новыми анимациями. В файтинге и штурме увеличены игровые сцены, уменьшены служебные элементы. «Экспедиция» получила движение между клетками и эффекты разведки/находок.

## Запуск

Распакуйте архив целиком в одну папку и откройте `index.html` двойным щелчком. Игры открываются из меню без отдельного сервера. Не запускайте файлы непосредственно внутри ZIP-архива.

При работе через локальный сервер можно по-прежнему выполнить в папке проекта:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Адрес: [http://127.0.0.1:8000](http://127.0.0.1:8000). На Windows вместо `python` может использоваться `py`.

Для размещения переносите всю папку проекта с сохранением структуры. Настройки безопасности браузера менять не нужно.

## Проверка после изменений

Нужен Node.js 18 или новее. Внешних зависимостей нет.

```sh
npm test
```

Только проверка синтаксиса, файлов и относительных ссылок:

```sh
npm run check
```

Обновление копии каталога после изменения тем:

```sh
node tests/catalog.cjs --write-catalog
```

Проверки включают генераторы, подсказки, меню, страницы предметов, относительные ссылки, реальные контроллеры игр, ответы, паузы, перезапуск и выход. Для новых предметов дополнительно выполнены 34 560 выдач заданий, 1920 запусков меню и 96 сценариев старых контроллеров. Новая игра проверена в настольном браузере; подробности — docs/primary-school.md и docs/lighthouse.md.

## Исправление локального запуска

Обычные отдельные iframe из локальных файлов могут иметь разные непрозрачные origin. Игра открывается через `iframe.srcdoc`, наследуя происхождение меню; абсолютный `<base>` внутри окна сохраняет правильные пути к внешним CSS, JS и изображениям. Движки и задания остаются в отдельных файлах.

`core/game-pages.js` собирается из 16 HTML-оболочек. После изменения HTML игры или добавления новой папки игры выполните:

```sh
npm run build
npm test
```

При изменении только движка, заданий, CSS или изображений пересобирать оболочки не требуется. `npm test` проверяет, что копия оболочек соответствует исходным HTML.

Для запуска с диска проверены пути Windows, пути с пробелами и Linux, а также URL подпапки сайта — автоматическими проверками. Попытка визуального запуска локального файла в среде подготовки заблокирована политикой браузера этой среды.

## Физика

Доступны 105 тематических пунктов и 25 разделов повторения: по четвертям и за год. Короткие вопросы охватывают основные разделы опубликованных типовых программ РК. Старшие классы — ЕМН. Это игровой тренажёр, который не заменяет полный курс, лабораторные и развёрнутые решения. Источники указаны в `content/physics/sources.json` и на странице предмета.

Задания включают прямые и обратные расчёты, перевод единиц, пропорциональные зависимости, качественные вопросы и применение нескольких формул. Значения физических постоянных приводятся в условии. Ответы численные без единицы, единица указана в вопросе; при необходимости округляйте до сотых.

В одиночном режиме помощник показывает формулу и разобранный аналогичный пример того же шаблона. Для постоянного качественного вопроса он поясняет сам вопрос. Пояснение меняется вместе с заданием.

В башнях на двоих числовой ответ вводится с клавиатуры. Для качественного вопроса в условии перечислены утверждения, ученик вводит номер правильного. Кнопки выбора ответа не добавляются. В гонках утверждение «верно/неверно» строится из физического вопроса, в лесу остаются три тропинки, в забеге сложность соответствует полосе.

Автопроверки: 33 280 физических заданий с независимой проверкой ответов; 320 запусков из меню по сочетаниям классов, четвертей, игр и режимов; каждый движок проверен с настоящим потоком физических вопросов. Проверки математики и локального запуска сохранены. Визуальная проверка локальных страниц в среде подготовки ограничена политикой браузера.

## Две новые игры с энергией

«Кубический рубеж»: ручной ввод полного числа, дроби, выражения или пропущенного слова; отдельные экранные клавиатуры игроков (числа, русский, английский, казахский, символы). Энергия расходуется на добычу, кирку и три постройки.

«Алхимическая мастерская»: выбор ответа пополняет энергию. Игрок сам выбирает рецепты, ингредиенты, нагрев и улучшение качества. Есть шесть рецептов и три сменяемых заказа.

Обе игры работают со всеми 18 предметами: соло на 3 минуты и одновременная дуэль на 150 секунд. Правила, формат ввода и проверка описаны в [документации](docs/energy-games.md).

В «Кубическом рубеже» добавлена подсказка с открытием следующей буквы: каждая буква уменьшает награду за текущий ответ на 1 энергию, минимум +1.


## Капсульный экспресс

Новая головоломка с падающими цветными парами. Тестовые ответы дают очки и заряды. Группы из четырёх кристаллов исчезают, последующие каскады увеличивают множитель. На широком экране — две независимые панели, на узком — вкладки игроков. Соло: 400 очков за 3 минуты; дуэль: больше очков за 150 секунд. Игра подключена ко всем 18 предметам. [Правила и проверка](docs/capsule.md).
